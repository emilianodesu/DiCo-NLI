3. **Identification of Constructive Advisories for M3**:
   - **Finding F-M2-01 (Minor)**: When `method="crl_sd"`, `build_model` wraps `SiameseCRLModel` in `SymmetrizedModelWrapper`. If a caller invokes `wrapper.predict_pair(text1, text2)`, `SymmetrizedModelWrapper` checks `hasattr(self.base_model, "predict_proba")`. Because `SiameseCRLModel` delegates encoding through `self.encoder` rather than exposing `predict_proba` directly, `wrapper.predict_pair` raises `NotImplementedError`. During batched inference with `wrapper.forward(...)`, this code path is not hit because `SiameseCRLModel.forward` computes SD predictions directly. Adding `elif hasattr(self.base_model, "encoder") and hasattr(self.base_model.encoder, "predict_proba"): ...` resolves this for standalone text pairs.
   - **Finding F-M2-02 (Minor / Advisory for GPU Mixed Precision)**: In `src/models/losses.py`, line 197 (`TranspositionOperator.forward` in PyTorch mode) performs `torch.matmul(probs, self.P)`. `self.P` is initialized as float32. Under mixed precision (`fp16`/`bf16`) in M3, `probs` will have dtype half/bfloat16. PyTorch requires identical dtypes for matrix multiplication. Updating line 197 to `torch.matmul(probs, self.P.to(dtype=probs.dtype, device=probs.device))` (identical to the pattern used in `decoding.py`) guarantees seamless execution on NVIDIA Tensor Cores.
